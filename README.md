# 基於多幀共識與幾何不變性之高效率全自動硬幣辨識系統
### High-Efficiency Automatic Coin Recognition System with Temporal Lifecycle Locking

本專案開發了一套基於 **傳統電腦視覺（OpenCV）** 的高效率不分區全自動硬幣辨識系統。在**不依賴任何深度學習模型與標註資料（No AI Training Required）**的前提下，利用純幾何數學特徵與時間軸濾波器，成功克服了極端複雜的鍵盤文字紋路干擾、畫面邊緣誤辨識、以及光影閃爍問題，完美適配嵌入式系統與 SoC 晶片的低功耗、低延遲實時運算規範。

---

## 核心技術亮點 (Key Features)

* **全畫面不分區辨識 (No Region Splitting)**：摒棄傳統寫死固定座標或人為劃分 ROI 遮罩的作法，演算法具備 100% 全畫面自主動態偵測能力。
* **幾何魯棒性 (Geometric Robustness)**：有效抵抗環境光影變化，調校 `dp=1.2` 參數空間網格，針對手機斜拍引起的「透視橢圓化畸變」與畫面邊緣的「幾何資訊截斷」進行數學容錯。
* **時間軸生命週期鎖定 (Temporal Lifecycle Locking)**：獨創多幀一致性驗證機制，消除傳統幾何演算法最嚴重的標註框閃爍（Flickering）痛點，同時確保硬幣動靜態轉換時絕不消失。
* **適配 SoC 實時處理 (Real-time Efficiency)**：純矩陣運算與統計排序，單幀演算法耗時符合工業級實時處理流速（< 0.1s）。
* **跨平台歸一化輸出 (Normalized Coordinate Output)**：自動將不同解析度的畫面座標，等比例映射轉換為雙位數相對百分比座標 `(0-100)`，確保跨平台解析度一致性。

## 演算法技術核心流程 (System Architecture)

本系統的處理架構分為四大核心層級：

```text
[ 原始視訊串流 ]
       │
       ▼
 1. 影像預處理 ───► 灰階轉換 + 7x7 中值模糊 (Median Blur) 消滅鍵盤高頻字體雜訊
       │
       ▼
 2. 特徵提取層 ───► 全畫面霍夫圓變換 (Hough Circles) 幾何法線投票鎖定圓心
       │
       ▼
 3. 共識驗證層 ───► 跨幀生命週期動態追蹤 (連續 16 幀共識驗證 + 緩慢衰減機制)
       │
       ▼
 4. 歸一化輸出 ───► 比例映射雙位數相對座標 (cx, cy) + 紅色方框與文字繪製

```

### 1. 影像預處理：從高斯模糊到中值模糊的工程權衡 (Trade-off)

雖然常規影像處理多採用高斯模糊（Gaussian Blur）進行平滑，但本專案在面對「複雜鍵盤背景」時進行了技術調整。鍵盤上的中文字體與注音符號屬於高對比的高頻訊號（類似胡椒鹽雜訊）。

* **高斯模糊的局限**：平均效應會導致字體邊緣暈開形成灰色干擾帶，且若加大半徑會使硬幣外圈幾何邊緣鈍化，引發一元硬幣漏抓。
* **中值模糊的優勢**：採用非線性空間濾波器 `cv2.medianBlur(gray, 7)`，利用鄰域統計排序取中位數的特性，**100% 直接抹平鍵盤字體**，同時**完美保留硬幣外圈銳利的階躍邊緣（Edge Preservation）**，為後續梯度計算奠定完美基礎。

### 2. 特徵提取層：參數空間投票與幾何不變性

利用圓形幾何中「邊緣法線（亮度梯度向量）必過圓心」的不變性，讓邊緣像素沿著梯度方向向參數空間累加器（Accumulator Matrix）進行投票。當無數射線在幾何中心點交會時，會在累加器矩陣中堆疊出強烈的局部極大值（Local Maxima）。

* 限制 `minRadius=30` 與 `maxRadius=50` 作為空間物理尺寸防線，徹底隔絕微小雜訊與巨大組合假圓。
* 當累積投票數超過 `param2=26` 門檻時，宣判鎖定圓心。

### 3. 技術痛點突破：克服「矩陣切片效應」與隨機噪訊

在開發過程中，曾嘗試引入動態背景分離（MOG2）、輪廓複檢（Contours）與局部 ROI 矩陣切片等機制，但發現當物件靠近畫面頂端邊緣（$y=0$）時，**邊界強制截斷（Boundary Truncation）會破壞幾何對稱性，且切片面積縮小（分母變小）會人為放大局部雜訊比（SNR崩潰）**，導致邊緣隨機誤抓與紅框暴走。

本系統最終透過「時間軸濾波器（Temporal Filter）」徹底根除此痛點：

* **多幀共識驗證 (Count Up)**：新偵測物件必須在相同像素區域內（距離 < 20px）**連續出現超過 16 幀（約 0.5 秒）**，系統才核發紅色物件框，直接免疫一閃而逝的隨機幾何巧合噪訊（如鍵盤縫隙、邊緣噪訊）。
* **生命週期衰減 (Decay)**：當硬幣短暫被手遮擋或消失時，標註框不立刻抹除，而是執行生命值緩慢遞減（Count - 1），維持畫面高度穩定度。
